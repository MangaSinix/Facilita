Política de Privacidade

Esta Política explica, de forma simples, como o [NOME DO CHAT/SERVIÇO] coleta, usa, armazena e protege dados pessoais quando você utiliza nosso chat e nossos recursos. Ela está alinhada à Lei Geral de Proteção de Dados (LGPD – Lei nº 13.709/2018).

1) Quem somos

O responsável pelo tratamento dos dados (Controlador) é [NOME/EMPRESA], [CPF/CNPJ], com contato em [E-MAIL DE CONTATO].

2) Quais dados podemos coletar

  • Dados de cadastro/contato: nome, e-mail, telefone (se você informar).
  • Dados do chat: mensagens enviadas, comandos utilizados e preferências (ex.: templates/configurações).
  • Identificadores técnicos: IP, data/hora de acesso, logs de erro, tipo de navegador/dispositivo e informações necessárias para segurança e funcionamento.
  • Dados de plataformas de terceiros: se você usar o chat via Telegram/WhatsApp/site, podemos tratar identificadores dessas plataformas (ex.: ID do usuário/grupo), conforme necessário para entregar a funcionalidade.

3) Para que usamos esses dados

  • Prestar e operar o serviço do chat (responder mensagens, executar funções e automações).
  • Manter segurança, prevenir abuso/fraudes e garantir estabilidade do sistema.
  • Melhorar a experiência e desempenho (ex.: correção de bugs, métricas técnicas).
  • Suporte e atendimento quando você solicitar ajuda.
  • Cumprir obrigações legais e responder a solicitações legítimas de autoridades, quando aplicável.

4) Bases legais (LGPD)

Tratamos dados com base em: execução de contrato (para entregar o serviço), legítimo interesse (segurança, prevenção de abuso e melhoria técnica) e, quando necessário, consentimento (por exemplo, para comunicações específicas). Você pode revogar o consentimento a qualquer momento, quando essa for a base aplicável.

5) Compartilhamento de dados

Não vendemos seus dados pessoais. Podemos compartilhar dados apenas quando necessário para:

  • Provedores de infraestrutura (ex.: hospedagem/servidores, banco de dados, CDN) para manter o serviço.
  • Serviços técnicos (ex.: monitoramento de erros e logs) para segurança e manutenção.
  • Obrigação legal: cumprimento de lei, ordem judicial ou requisição válida.

6) Armazenamento e prazo de retenção

Guardamos dados pelo tempo necessário para cumprir as finalidades desta Política, inclusive para segurança, suporte e obrigações legais. Quando possível, dados são excluídos, anonimizados ou agregados após o período necessário.

7) Segurança

Adotamos medidas técnicas e organizacionais para proteger dados contra acesso não autorizado, perda e uso indevido (ex.: controle de acesso, logs de auditoria, boas práticas de servidores). Ainda assim, nenhum sistema é 100% seguro.

8) Direitos do titular

Você pode solicitar: confirmação de tratamento, acesso, correção, anonimização, portabilidade, eliminação, informação sobre compartilhamento e revogação de consentimento, conforme a LGPD. Para exercer seus direitos, fale conosco em [E-MAIL DE CONTATO].

9) Cookies (se este site usar)

Podemos usar cookies/armazenamento local para manter preferências e melhorar o funcionamento do site. Você pode gerenciar cookies nas configurações do seu navegador.
