Política de Privacidade

Esta Política explica, de forma simples, como o [Facilita Divulgador] coleta, usa, armazena e protege dados pessoais quando você utiliza nossos recursos.

Última atualização: [17/12/2025]

1) Quem somos

O responsável pelo tratamento dos dados (Controlador) é [NOME/EMPRESA], . Contato: facilitadivulgador@gmail.com.

2) Quais dados podemos coletar

  • Dados de contato: nome, e-mail, telefone (se você informar).
  • Dados do chat: mensagens, comandos e preferências (ex.: templates/configurações).
  • Dados técnicos: IP, data/hora, logs de erro e informações de navegador/dispositivo.
  • Terceiros: identificadores de plataformas (ex.: Telegram/WhatsApp), quando necessário para a função do serviço.

3) Para que usamos os dados

  • Operar o chat e entregar as funcionalidades.
  • Segurança, prevenção de abuso/fraudes e estabilidade.
  • Melhorias técnicas (correção de bugs e performance).
  • Suporte quando solicitado.
  • Cumprimento de obrigações legais quando aplicável.

4) Bases legais (LGPD)

Tratamos dados com base em execução de contrato, legítimo interesse (principalmente segurança e melhoria técnica) e, quando necessário, consentimento. Você pode revogar o consentimento quando essa for a base aplicável.

5) Compartilhamento

Não vendemos seus dados pessoais. Podemos compartilhar apenas quando necessário para:

  • Infraestrutura (hospedagem/servidores, banco de dados, CDN).
  • Serviços técnicos (monitoramento de erros/logs) para manutenção e segurança.
  • Obrigação legal, ordem judicial ou requisição válida.

6) Retenção

Guardamos dados pelo tempo necessário para cumprir as finalidades acima e obrigações legais. Quando possível, excluímos, anonimizamos ou agregamos dados após o período necessário.

7) Segurança

Aplicamos medidas técnicas e organizacionais para proteger dados (controle de acesso, boas práticas de servidores e monitoramento). Nenhum sistema é 100% imune, mas trabalhamos para reduzir riscos.

8) Seus direitos

Você pode solicitar acesso, correção, eliminação, portabilidade, informações sobre compartilhamento e revogação de consentimento, conforme a LGPD. Contato: facilitadivulgador@gmail.com.

9) Cookies (se este site usar)

Podemos usar cookies/armazenamento local para preferências e funcionamento do site. Você pode gerenciar isso nas configurações do navegador.

10) Alterações

Podemos atualizar esta Política. Mudanças relevantes serão publicadas nesta página com a data de atualização.
